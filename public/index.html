The Canon uses Android’s regular print dialog. The MUNBYN ITPP130B supports an experimental direct Bluetooth connection from Chrome on Android. Connect once and print a test label; Piko will look for the saved printer and retry a failed connection after refreshing the page. Print labels without a PDF.

Restoring saved printer if Chrome permits. Keep Bluetooth enabled and close MUNBYN Print.

Remember MUNBYN after Chrome refresh (experimental)

On your Android tablet, open chrome://flags in Chrome. Enable Experimental Web Platform features and, if listed, Web Bluetooth new permissions backend. Relaunch Chrome, return here, tap Connect MUNBYN once, and refresh to test. These flags are experimental and can change Chrome behavior. If one is missing or it still does not reconnect, normal Android Chrome cannot guarantee automatic reconnection. A native Android Bluetooth bridge is the reliable alternative.
